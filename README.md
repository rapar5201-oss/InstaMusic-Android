# InstaMusic Android

Android WebView app for https://instamusic.lovable.app, with the supplied split-screen orange-and-black animated launch and light/dark launcher icons.

The app loads the live site, so published web changes appear without an APK reinstall. GitHub Actions rebuilds the installable debug APK when this repository's `main` branch changes and updates the latest APK release.

Download: https://github.com/rapar5201-oss/InstaMusic-Android/releases/latest
